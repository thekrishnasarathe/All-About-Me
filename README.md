## 🚀 Quickstart & Local Setup

### Prerequisites
- Node.js `20.x` or later
- npm or pnpm

### 1. Clone & Install
```bash
git clone https://github.com/thekrishnasarathe/portfolio.git
cd portfolio
npm install
```

### 2. Environment Configuration
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```
Add your optional Google Gemini API key:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(The portfolio runs 100% smoothly without an API key; the key is only required if you want live interactive AI responses from the assistant drawer).*

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3002](http://localhost:3002) in your browser.

## ☁️ $0 Free-Tier Vercel Deployment

1. Push your repository to **GitHub**:
   ```bash
   git add .
   git commit -m "chore(release): production hardening, experience, and certificates"
   git push origin main
   ```
2. Log in to [Vercel](https://vercel.com) and click **Add New > Project**.
3. Import your `portfolio` repository.
4. Keep the default Next.js settings:
   - **Framework Preset**: `Next.js`
   - **Build Command**: `npm run build`
   - **Output Directory**: `.next`
5. *(Optional)* Add `GEMINI_API_KEY` under **Environment Variables**.
6. Click **Deploy**. Vercel will build and launch your portfolio on a global edge CDN with automatic SSL!
